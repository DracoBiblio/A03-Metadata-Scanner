# A03-Metadata-Scanner
A03 Metadata Scanner for Calibre
a scanner that can find Fandom(s), ship(s), and series in A03 metadata so it can be put in to columns in calibre for better organization.
working for epub at the moment hoping to add other formats later.
Not the best build but functional

IMPORTANT:

3. BUILT-IN CALIBRE COLUMNS

The plugin also uses these existing Calibre columns:

Tags – for AO3 Additional Tags
Series – for AO3 Series information

You do not need to create a separate Series column.
